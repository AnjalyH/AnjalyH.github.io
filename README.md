## Run locally

No installation needed. Download or clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/AnjalyH/AnjalyH.github.io.git
cd AnjalyH.github.io
# open index.html in your browser
```

## Deploy with GitHub Pages

1. Push `index.html` and `Anjaly_Resume.pdf` to the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save, and the site goes live in a minute or two.

## Updating the resume

Replace `Anjaly_Resume.pdf` with the new file and keep the same filename. The Download resume button always links to it.
